# GvozdepediaMTG

Энциклопедия моего мира Magic: The Gathering: колоды, мысли о них, гайды, новости, турниры по EDH.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:5173. Сборка для публикации: `npm run build` (готовые файлы в `dist/`).

## Публикация на GitHub Pages

1. Создай пустой репозиторий на GitHub (например, `GvozdepediaMTG`, Public, без README).
2. Отправь туда код (`<username>` — твой ник на GitHub):
   ```bash
   git remote add origin https://github.com/<username>/GvozdepediaMTG.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Source: GitHub Actions**.
4. Через 1–2 минуты сайт будет на `https://<username>.github.io/GvozdepediaMTG/`.
   Каждый push (и каждое сохранение из редактора) пересобирает сайт автоматически.

## Режим редактора

Все посетители видят сайт, но редактировать может только тот, у кого есть право записи в репозиторий.

1. Внизу меню нажми **Войти**.
2. Создай fine-grained токен на GitHub (ссылка и инструкция есть в окне входа):
   доступ только к репозиторию сайта, разрешение **Contents: Read and write**.
3. Вставь токен — появятся кнопки **+ Новая колода**, **✎ Редактировать** и **Удалить колоду**.

Сохранение — это коммит в репозиторий. У тебя изменения видны сразу, у остальных — после пересборки (1–2 минуты).
Токен хранится только в твоём браузере; **Выйти** его удаляет.

## Крутые карты

Раздел `#/cards` — карты, которые нравятся. Редактор добавляет их прямо на сайте: подсказки по названию,
как на Scryfall, а Enter запускает полный поиск с [синтаксисом Scryfall](https://scryfall.com/docs/syntax)
(`t:artifact o:token`, `c:r cmc<=2` и т.д.). К карте можно написать заметку, чем она нравится.
Список хранится в `content/cards.json`.

## Как добавить колоду вручную

Создай файл `content/decks/<имя-латиницей>.md` — он сразу появится в меню и на главной.
Адрес страницы будет `#/decks/<имя-латиницей>`.

```markdown
---
name: Название колоды
commander: Krenko, Mob Boss
moxfield: https://moxfield.com/decks/...
---

## Праймер
Короткое описание колоды (markdown).

## Мысли о колоде
Что нравится, что нет, планы (markdown).

## Деклист
1 Sol Ring
30 Mountain
...
```

- Деклист можно вставить прямо из Moxfield: **Export → Copy for MTGO / Plain text**. Сеты и пометки фойла (`(CMM) 400 *F*`) понимаются.
- Два командира (партнёры): `commander: Thrasios, Triton Hero | Tymna the Weaver`.
- Если командир есть в деклисте — он автоматически пропускается.
- Названия карт — на английском, как на Scryfall. Карты, которые не нашлись, показываются отдельной красной группой.

Картинки, мана-стоимость, типы и цены подтягиваются со [Scryfall](https://scryfall.com) и кэшируются в браузере на неделю.
